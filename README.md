# Projet-de-statistique
Ce projet analyse un jeu de données sur les jeux vidéo afin d’identifier les facteurs influençant le score utilisateur. Après nettoyage et analyses statistiques, les résultats montrent que le genre, la franchise, la plateforme et l’éditeur ont un impact significatif, tandis que les ventes seules expliquent peu la satisfaction des joueurs.
